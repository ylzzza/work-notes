# 登录 AGIC 模拟器（cdai007）

连接顺序：**本机 Mac → cdai007 宿主机 → QEMU 内的模拟器**。

| 项目 | 当前配置 |
| --- | --- |
| 本机 SSH 别名 | `cdai007`，沿用本机已配置的跳板与账号 |
| 宿主机账号 | `yelinzhong` |
| 模拟器 SSH | 宿主机上的 `127.0.0.1:15085` → Guest 22 端口 |
| 模拟器账号 / hostname | `root` / `simnpu` |
| 平台目录（宿主机） | `/localhome/yelinzhong/AGIC_Virtual_Platform` |
| tmux 会话 | `agic-vp-a510-15085` |

## 1. 快速登录：模拟器已经启动

**在本机 Mac 终端执行：**

```bash
ssh -tt -o ClearAllForwardings=yes cdai007 \
  'ssh -tt -p 15085 root@127.0.0.1'
```

也可以分两步：

```bash
# 本机：登录宿主机
ssh -o ClearAllForwardings=yes cdai007

# 进入 cdai007 后：登录模拟器
ssh -p 15085 root@127.0.0.1
```

> [!tip] 当前镜像的登录密码
> 本次验证的 root 密码是**一个空格**：提示密码时，按一次空格，再按回车。终端输入密码时不会回显。后续如果改过密码，使用修改后的密码。

> [!important] 127.0.0.1 指哪台机器
> `ssh -p 15085 root@127.0.0.1` 要在 **cdai007 上**执行。这里的 `127.0.0.1` 指 cdai007，不是本机 Mac。

登录后确认：

```bash
hostname
id -un
```

预期分别输出 `simnpu` 和 `root`，提示符类似 `root@simnpu:~#`。

## 2. 需要启动模拟器时

### 先在宿主机检查实例

```bash
ssh -o ClearAllForwardings=yes cdai007
ss -ltnp 'sport = :15085'
tmux list-sessions
```

如果 15085 已由对应 QEMU 监听，直接按上面的登录步骤连接。查看已有会话的输出：

```bash
tmux capture-pane -p -t agic-vp-a510-15085 -S -100
```

### 新建 tmux 会话

确认没有运行中的对应实例，且同名 tmux 会话不存在后，在 **cdai007** 执行：

```bash
tmux new-session -s agic-vp-a510-15085 \
  -c /localhome/yelinzhong/AGIC_Virtual_Platform
```

### 在新建的 tmux 内启动 QEMU

下面整段在 **cdai007 的 tmux 内**执行，`$HOME`、`$USER` 使用宿主机的值。

```bash
cd /localhome/yelinzhong/AGIC_Virtual_Platform

bin/run_qemu.sh \
  -chip a510 -model fmodel \
  -cards 1 -chips 2 -dies 1 \
  -i "/home/yelinzhong/agic-vp-images/ubuntu-22.04-agic-vp.qcow2" \
  -e "-m 200G -smp 8 -net user,hostfwd=tcp:127.0.0.1:15085-:22 -net nic \
      -fsdev local,security_model=none,id=fsdev0,path=/sw/public/env/sim_npu/share \
      -device virtio-9p-pci,id=fs0,fsdev=fsdev0,mount_tag=mnt_shared \
      -fsdev local,security_model=none,id=fsdev1,path=/localdata/env/sim_npu/user/$USER \
      -device virtio-9p-pci,id=fs1,fsdev=fsdev1,mount_tag=mnt_self \
      -fsdev local,security_model=none,readonly=on,id=fsdev2,path=/tools \
      -device virtio-9p-pci,id=fs2,fsdev=fsdev2,mount_tag=mnt_tools \
      -fsdev local,security_model=none,readonly=on,id=fsdev3,path=/ai \
      -device virtio-9p-pci,id=fs3,fsdev=fsdev3,mount_tag=mnt_ai \
      -fsdev local,security_model=none,readonly=on,id=fsdev4,path=/ai/db500_data \
      -device virtio-9p-pci,id=fs4,fsdev=fsdev4,mount_tag=mnt_scratch"
```

配置为 A510 FModel、1 card × 2 chips × 1 die、200G 内存、8 vCPU。镜像默认可读写，Guest 内的改动会保存到该 qcow2。

先按 `Ctrl+b`，松开后按 `d`，即可脱离 tmux，模拟器继续运行。然后在本机另开一个终端，执行“快速登录”命令。

重新查看启动终端：

```bash
# cdai007 上执行；进入后用 Ctrl+b，再按 d 脱离
tmux attach -t agic-vp-a510-15085
```

## 3. 共享目录映射

宿主机 `/sw/public/env/sim_npu` 是 `/localdata/env/sim_npu/` 的软链接。

| cdai007 上的目录 | 模拟器内目录 | 权限 |
| --- | --- | --- |
| `/sw/public/env/sim_npu/share` | `/home/agic/share` | 读写 |
| `/sw/public/env/sim_npu/user/yelinzhong` | `/home/agic/self` | 读写 |
| `/tools` | `/tools` | QEMU 后端只读 |
| `/ai` | `/ai` | QEMU 后端只读 |
| `/ai/db500_data` | `/scratch` | QEMU 后端只读 |

在**模拟器内**确认挂载：

```bash
findmnt -t 9p -o SOURCE,TARGET,FSTYPE,OPTIONS
ls -ld /home/agic/share /home/agic/self /tools /ai /scratch
```

例如，宿主机上的 `/sw/public/env/sim_npu/share/yelinzhong/AGICServing`，在模拟器内对应 `/home/agic/share/yelinzhong/AGICServing`。

## 4. 登录后加载 AGICServing 环境

在**模拟器内**执行：

```bash
cd /home/agic/share/yelinzhong/AGICServing
export AGIC_RANK_CONFIG_PROFILE=simulator
export TILE_NUM=16
source env_setup_agic.sh AGIC_BACKEND=db500
```

首次安装环境时，先在该目录执行：

```bash
make dev AGIC_BACKEND=db500
```

本次验证使用 `/root/.agicenv_22/venv`。完整部署与运行命令见 [[AGICServing]]。

## 5. 退出与停止

- 在 Guest 内执行 `exit`：退出模拟器 SSH，QEMU 继续运行。
- 在 tmux 内按 `Ctrl+b`，再按 `d`：脱离启动终端，QEMU 继续运行。
- 需要停止模拟器时，在 **Guest 内**执行 `sync; poweroff`，等待对应 QEMU 正常退出。

## 常见问题

- **出现 `remote port forwarding failed`**：本笔记的宿主机登录命令已加 `-o ClearAllForwardings=yes`，避免沿用无关的 SSH 端口转发。
- **15085 未监听或 SSH 暂时连不上**：查看该 tmux 的启动输出，确认 QEMU 仍运行并等待 Guest 启动完成。
- **找不到 `/sw/public/env/sim_npu/`**：这是宿主机路径；Guest 内使用上表的 `/home/agic/share` 等挂载点。
- **提示密码错误**：确认登录的是 `root@127.0.0.1:15085`，并按当前镜像实际密码输入；空格密码需要真的按一次空格。
