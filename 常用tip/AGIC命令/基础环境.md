## 登录模拟器

**普通模式**
```bash
cd /sw/public/env/sim_npu
FAST_MODE=1 QEMU_MEM_USE=200 ./launch.sh -n 6
```

**TCP 模拟**
```bash
cd /sw/public/env/sim_npu_new
QEMU_MEM_USE=300 FAST_MODE=1   ./launch.sh -n 4 -c /sw/public/env/sim_npu/share/dev_fw/a510/A5XX_Linux_SDK/ap_execute/
```


### 分布式模拟器
```
cd /sw/public/env/sim_npu
FAST_MODE=1 QEMU_MEM_USE=200 ./launch.sh -r -l share/accl_env_setup_2switch.sh -n 11
```
