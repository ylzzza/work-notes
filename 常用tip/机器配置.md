## 步骤3：安装 Codex

### 1. 安装 nvm

```bash
mkdir -p ~/.nvm
curl -L https://github.com/nvm-sh/nvm/archive/refs/tags/v0.40.3.tar.gz -o /tmp/nvm.tar.gz
tar -xzf /tmp/nvm.tar.gz -C ~/.nvm --strip-components=1
```

### 2. 配置 nvm 环境变量

将以下内容追加到 `~/.bashrc`：

```bash
cat >> ~/.bashrc <<'EOF'
export NVM_DIR="$HOME/.nvm"
[ -s "$NVM_DIR/nvm.sh" ] && . "$NVM_DIR/nvm.sh"
[ -s "$NVM_DIR/bash_completion" ] && . "$NVM_DIR/bash_completion"
EOF
```

使配置生效：

```bash
source ~/.bashrc
```

检查 nvm 是否安装成功：

```bash
nvm --version
```

### 3. 安装 Node.js LTS 版本

```bash
nvm install --lts
```

检查 Node.js 和 npm 版本：

```bash
node -v
npm -v
```

### 4. 安装 Codex

```bash
npm install -g @openai/codex
```

检查 Codex 是否安装成功：

```bash
codex --version
```

## 步骤4：配置 Git

### 1. 安装并检查 Git

```bash
git --version
```

如果机器未安装 Git，可按系统安装：

```bash
# Ubuntu / Debian
sudo apt update
sudo apt install -y git

# CentOS / RHEL
sudo yum install -y git

# macOS
brew install git
```

### 2. 配置用户信息

将下面的姓名和邮箱替换成自己的 Git 提交身份：

```bash
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
```

检查配置：

```bash
git config --global --list
```

### 3. 配置常用默认项

```bash
# 默认分支名
git config --global init.defaultBranch main

# 拉取时使用 rebase，避免无意义 merge commit
git config --global pull.rebase true

# 自动处理 rebase 过程中的 stash
git config --global rebase.autoStash true

# 记住 HTTPS 凭证（如主要使用 SSH，可跳过）
git config --global credential.helper store
```

### 4. 配置 SSH Key

如果本机已经有可用 SSH Key，可直接查看公钥：

```bash
cat ~/.ssh/id_rsa.pub
```

如果没有，则新建一个：

```bash
ssh-keygen -t ed25519 -C "your.email@example.com"
```

启动 ssh-agent 并添加私钥：

```bash
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519
```

将公钥复制到 Git 平台（GitHub / GitLab / 公司 Git 服务）：

```bash
cat ~/.ssh/id_ed25519.pub
```

### 5. 配置 Git 平台 Host（可选）

在 `~/.ssh/config` 中增加：

```sshconfig
Host github.com
  HostName github.com
  User git
  IdentityFile ~/.ssh/id_ed25519
  IdentitiesOnly yes
```

如果公司 Git 平台需要跳板机，可参考前面的 SSH `ProxyJump` 配置。

### 6. 测试连接

```bash
ssh -T git@github.com
```

如果看到认证成功或欢迎信息，说明 SSH 配置正常。

### 7. 克隆仓库

优先使用 SSH 地址：

```bash
git clone git@github.com:owner/repo.git
```

进入仓库后检查远程地址：

```bash
git remote -v
```
